# 麦麦团餐管家 · mcd-catering-butler

> 给企业行政、HR 和团队负责人的麦当劳团餐统筹助手。告诉它人数、预算、忌口，它给你一份能直接拿去审批的三档方案。

基于麦当劳中国官方 MCP 服务开发，参赛作品。

---

## 它解决什么问题

个人点麦当劳，纠结的是「今天吃啥」。企业团餐，纠结的是另外六件事：

| 组织者真实痛点 | 现在怎么解决 |
|---|---|
| 30 人吃饭，预算 900，人均卡在多少 | 给定总预算，自动反算三档人均 |
| 有 2 个同事不吃辣、1 个素食 | 按忌口过滤菜单，无法满足时明确告知而非硬凑 |
| 报销时财务问「为什么超了 200」 | 每档都带结余明细与超标预警，超标部分单独标出 |
| AA 还是公司报销，每人该收多少 | 三种分摊模式直接出数 |
| 门店能不能送、多少份起送 | 调 MCP 查配送门店与团餐助餐服务 |
| 团建想订麦当劳派对，有没有场次 | 城市→门店→日期→场次四级筛选 |

它不做的事也很明确：**不代下单、不给营养建议、不承诺价格**。下单前的最后一步永远交回给人。

## 快速开始

### 1. 拿一个麦当劳 MCP Token

到 [open.mcd.cn/mcp](https://open.mcd.cn/mcp) 用手机号登录 → 右上角「控制台」→「激活」→ 复制 Token。

### 2. 在 WorkBuddy 里接上 MCP

左侧边栏【专家·技能·连接器】→【连接器】页签 → 右上角【自定义连接器】→【配置 MCP】，填入：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

把 `YOUR_MCP_TOKEN` 换成你的真实 Token，保存，然后启用 `mcd-mcp`。

### 3. 开始用

在对话框里直接说：

> 我们部门 30 人下周三聚餐，预算 1000，公司报销，有两个人不吃辣，帮我配个麦当劳团餐方案

Skill 会自动拉门店、拉菜单、跑引擎、给方案。

### 只想先看看跑起来什么样

不需要 Token，用内置示例菜单即可：

```bash
python scripts/catering_planner.py --people 50 --budget 1500
```

零第三方依赖，Python 3.9+ 直接跑。

## 它怎么算的

团餐方案不是「挑几个贵的凑够钱」，得同时满足多个约束。引擎分三步收敛：

**第一步：按类别分配预算。** 主食占 70%、小食 20%、饮品 10%，每类在预算内挑最贵的可行 SKU。主食按 7:3 拆两个价位相近的 SKU，避免一桌人全吃同一款。

**第二步：超预算就降级。** 按「降级收益 × 品类权重」排序，每次挑性价比最高的一处降级。权重设计体现业务判断：**饮品权重 3.0、小食 0.8、主食 0.5**——预算不够时先砍饮品，主食是团餐的体面，尽量不动。

**第三步：降无可降就减份数。** 饮品最低减到人数的 40%，小食最低 6%。真实组织者就是这么调预算的，不会只换更便宜的品项。

三步都在 `target × 0.97` 处收敛，留 3% 给配送费与价格波动，避免方案贴边到只剩 1 元结余。

### 边界情况怎么处理

| 输入 | 行为 |
|---|---|
| 素食（`--diet vegetarian`） | 麦当劳菜单无纯素主食，引擎用小食顶上主食位，并输出预警「建议为特殊饮食需求者单独选购」 |
| 预算连最便宜组合都不够 | 不假装能凑出来，输出「当前菜单无法压进该档预算，仍超 ¥X」并给三个调整方向 |
| 备选 SKU 价差过大 | 限制在主选的 0.75~1.25 倍内，否则退回单一 SKU，避免方案忽高忽低 |

## 用到的麦当劳 MCP 工具

| 分组 | 工具 |
|---|---|
| 门店与基础 | `now-time-info`、`query-nearby-stores`、`delivery-query-stores`、`delivery-query-addresses` |
| 餐品与价格 | `query-meals`、`query-meal-detail`、`list-nutrition-foods`、`calculate-price` |
| 优惠与账户 | `query-store-coupons`、`available-coupons`、`query-my-coupons`、`auto-bind-coupons` |
| 团餐与活动 | `query-meal-assistance`、`query-party-city`、`query-party-store`、`query-partystore-date`、`query-partystore-session`、`party-order-create` |

调用顺序、顺序背后的原因、错误码处理，全部写在 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。
